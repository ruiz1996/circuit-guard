# 回路守卫 · Circuit Guard

受无尽塔防玩法启发的原创本地单机游戏原型。独立实现规则、界面、几何美术和关卡，无需原游戏服务器，不包含原游戏代码与素材。

## 开始游戏

双击本目录中的 **启动游戏.cmd**，或使用浏览器打开 **index.html**。不需要安装依赖或联网，建议使用现代 Edge、Chrome 或 Firefox。

也可以安装 Node.js 后在此目录运行 `npm start`，访问终端显示的本地地址（默认 http://127.0.0.1:4173）。直接打开文件和通过本地地址打开的浏览器存档彼此独立。

## 玩法

- 选择建筑后点击地图空地建造，再点击“开始第 1 波”。道路上不能建塔。
- 六类建筑：脉冲塔、狙击塔、榴弹塔、霜环塔、电弧塔、采晶器。
- 三张原创地图。采晶器只能放在菱形矿脉，战斗期间产出研究晶体与金币。
- 点击已部署建筑可以升级（最高 5 级）、切换攻击目标，或回收总投入的 70%。非采晶建筑通过击破敌人积累经验并获得伤害提升。
- 敌人包括常规、疾行、装甲、集群和每 10 波出现的领主。波数无上限，敌人生命与数量逐渐增加。
- 核心完整度归零则结算。普通敌人漏过损失 1 点，领主损失 5 点。
- 每波奖励和采晶收益可以用于八类永久研究。重新出发和切换地图保留晶体、研究和最高纪录；初始资金与核心研究在下次战斗生效。
- 支持暂停、1/2/3 倍速、自动波次、可选合成音效。

快捷键：`1`–`6` 选择建筑；`U` 升级选中的塔；`Esc` 取消选择或关闭面板；空格开始下一波或暂停/继续交战。

## 存档

自动保存在当前浏览器的 localStorage 中，关闭后再打开可以继续。打开研究、地图、指南等面板时暂停；切到其他标签页时暂停。恢复存档后需点击继续。

指南内可以导出、导入 JSON 存档。清除浏览器数据会删除本地存档；不同浏览器、不同地址的存档互不共享。私密浏览或禁止本地存储时可能无法保存，请导出备份。

## 开发与验证

无第三方运行依赖。使用 Canvas 2D 绘制画面，游戏规则与界面分开。

- `engine.js`：战斗模拟、建筑、波次、研究与存档快照。
- `app.js`：交互、绘制、音效、本地存档。
- `style.css`：响应式界面。
- `npm test`：关键规则测试。
- `npm run check`：JavaScript 语法检查。

这是可玩的第一版，尚未包含原作规模的剧情、排行榜、跨设备云存档和关卡编辑器。

## GitHub Pages

这是一个无需构建的静态网站，所有资源都使用相对路径，可直接部署到 GitHub Pages 的项目子目录。

在仓库的 Settings → Pages 中，选择 **Deploy from a branch**，选默认分支和 **/(root)**，然后保存。仓库根目录中的 `.nojekyll` 会让 Pages 直接提供静态文件。

手机使用 Safari、Chrome 或 Edge 打开 Pages 链接即可。先在上方选择防御塔，再点击地图空地建造，点击开始波次。手机存档保存在手机当前浏览器中，与电脑存档独立；需要转移时，可在指南中导出和导入存档。
